### 3. Character & Style Ideas for 돌잔치 / Baby Invitations

1. **Pastel Chibi Horse (파스텔 꼬마 말)** — Soft mint, baby pink, or peach colors with big eyes. Highly suitable for modern, cute invitations.
   Examples: [Irasutoya "Pony"](https://www.irasutoya.com/2013/05/blog-post_1387.html), [Freepik Kawaii Pony](https://www.freepik.com/search?query=kawaii%20pony).
2. **Rocking Horse Toy (흔들목마)** — Symbolizes infancy, playfulness, and safety. A classic motif for 1st birthdays that avoids looking like a "wild" animal.
   Examples: [Flaticon Rocking Horse](https://www.flaticon.com/search?word=rocking%20horse), [Pixabay Rocking Horse](https://pixabay.com/vectors/search/rocking%20horse/).
3. **Hanbok-Wearing Horse (한복 입은 말)** — Perfect for a traditional Dol (돌잔치), especially relevant for babies born in a Horse year (2026 병오년).
   Examples: Often found in [공유마당 (Gongu)](https://gongu.copyright.or.kr/) or as elements inside MiriCanvas templates.
4. **Pony with Braided Mane / Floral Wreath** — Fairy-tale, botanical vibe. Matches well with floral web borders.
   Examples: Search Freepik for "horse floral wreath vector".
5. **Unicorn-without-horn Hack** — Unicorn illustrations tend to have the best pastel/rainbow color palettes.
   Trick: Download a CC0 or fully modifiable SVG unicorn (e.g., from SVG Repo) and simply delete the `<path>` for the horn in the code.

### 4. Practical Notes & Rules of Thumb

* **Format (SVG vs PNG)**: Use SVG for infinite scaling and CSS color control; use PNG for complex watercolor textures/shading (ensure transparent background).
* **Attribution Text**: If you use CC BY or Freepik free tiers, include a small footer credit (e.g., `<p style="font-size: 10px;">Horse vector designed by <a href="...">Freepik</a></p>`).
* **Modification**: CC0, MIT, Pixabay, and KOGL Type 1 allow free recoloring/edits. CC BY-ND (NoDerivs) does *not* allow changes.
* **Logo/Mascot Restrictions**: Almost all free sites (Irasutoya, Freepik, Pixabay) prohibit use as a registered company logo/official mascot, but decorative use on a one-off personal birthday page is fine.
